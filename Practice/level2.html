Procurement Management System

**Procurement Management System:** Developed and maintained an enterprise-level **Source-to-Pay (S2P) Procurement System** using
**Java, Spring Boot, Spring Data JPA, Hibernate, REST APIs, Microservices, and MySQL**. The system manages the complete procurement lifecycle, including
**Purchase Requisition (PR), Budget, Purchase Order (PO), Vendor, Invoice, and User Management**. Implemented and integrated RESTful APIs between multiple microservices using an **API Gateway**, handled database operations using JPA/Hibernate, and implemented validations, exception handling, and business logic. Used **Postman** for API testing and **Git/Jira** for development and project tracking. The system helps organizations streamline procurement processes, improve vendor management, control budgets, and efficiently track purchase orders and invoices.
